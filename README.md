# ANOMALY CONTAINMENT 공식 배포

이 저장소는 Windows 실행용 게임과 업데이트 파일만 제공합니다. Unity 프로젝트와 서버 소스는 비공개 개발 저장소에서 관리합니다.

## 다운로드

[최신 정식 릴리스](https://github.com/SJYEOBI/anomaly-containment-releases/releases/latest)

- 처음 설치: `AnomalyContainment-Windows-v버전.zip` 전체를 풀고 `AnomalyContainment.exe`를 실행하세요.
- 기존 v0.9.0 이하 사용자: 릴리스의 `AnomalyContainment-Updater.zip`을 받아 기존 게임 실행 파일 옆에 풀고, 게임 종료 후 `AnomalyContainment-Update.exe`를 실행하세요.
- 새 업데이터 설치 이후에는 게임 환경설정의 업데이트 버튼이나 전용 업데이트 프로그램을 사용하면 됩니다.
- 이전 개발 저장소가 비공개로 바뀌면 구형 업데이터는 동작하지 않습니다. GitHub 로그인이나 접근 토큰을 게임에 입력할 필요는 없습니다.
- 협동 참가자는 모두 같은 버전을 사용하세요. 기존 세이브는 유지되며 계정으로 이전할 수 있습니다.

## 배포 파일

전체 게임 ZIP, 이전 버전 대비 패치, 업데이트 매니페스트, 업데이터 ZIP, SHA256 목록을 제공합니다. 소스 코드 ZIP은 게시하지 않습니다. GitHub에서 자동 생성하는 Source code 압축에는 이 배포 저장소의 안내 문서만 들어 있습니다.

외부 에셋의 출처와 라이선스는 게임 배포본의 ThirdParty 문서를 확인하세요.
